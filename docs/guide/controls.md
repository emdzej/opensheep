# Controls

The original's defaults. The front end's options choose the controller: mouse, keyboard, analog pad
or digital pad. M, K and J switch between mouse, keyboard and pad during a level.

| In the game | Keyboard | Mouse | Pad |
|---|---|---|---|
| Move the shepherd | Arrow keys | Move the mouse | D-pad or left stick |
| Run | Left Shift | Left button | Button 1 |
| Creep, activate, pick up, throw | Left Alt | Right button | Button 2 |
| Shout, drop sweets | Space | Space | Button 3 or Space |
| Map (hold) | Tab | Tab | Button 4 or Tab |
| Pause menu | Esc | Esc | Esc |

"Activate" in the game's texts ("Press activate to exit level") is the creep button.

Menus use the arrow keys, Enter and Esc, or the mouse.

In the browser, the mouse is captured while you play with it (click the game); Esc releases it.
Holding Esc for a second stops the game.

On Windows, Left Alt with Left Shift switches the keyboard layout when more than one is installed.
That is the system's shortcut, and neither the game nor the browser can block it: remove the spare
layout, or change the shortcut in the language settings.
