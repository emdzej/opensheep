# Introduction

Sheep (Mind's Eye Productions / Empire Interactive, 2000) is a puzzle game about herding. You play
one of four shepherds and steer a flock across a level to its pen before
the clock runs out. Sheep don't follow you: they keep
away from you, so you herd by where you stand.

OpenSheep is a reimplementation of the Windows game, ported routine by routine from the original
program, `Sheep.exe`. It isn't an emulator: the game logic runs as portable C, and it reads
everything it needs (graphics, levels, movies, sound and the program's own tables) from your Sheep
CD at run time. It contains no part of the original game.
